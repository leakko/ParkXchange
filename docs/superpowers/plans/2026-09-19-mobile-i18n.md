# Mobile i18n (ES / EN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spanish/English UI in `apps/mobile` with local AsyncStorage preference, system-English→en else→es default, immediate Profile toggle.

**Architecture:** Custom `I18nProvider` + typed `es`/`en` dictionaries; `resolveLocale` + AsyncStorage; no API changes.

**Tech Stack:** Expo 57, React Native, `expo-localization`, `@react-native-async-storage/async-storage`, Node test runner (existing mobile pattern).

## Global Constraints

- Mobile only — no Go / OpenAPI / DB
- Default: English device → `en`, else `es`
- Preference local-only; survives relaunch; applies immediately
- Do not translate raw API error message bodies
- Dates use active locale via `toLocaleString`

## File map

| File | Responsibility |
| --- | --- |
| `apps/mobile/src/i18n/types.ts` | `AppLocale`, `TranslationKey`, message shape |
| `apps/mobile/src/i18n/locales/es.ts` | Spanish copy |

| `apps/mobile/src/app/_layout.tsx` | Wrap provider |
| `apps/mobile/src/app/account/profile.tsx` | Language picker |
| All UI screens / sheets | Replace hard-coded strings with `t()` |
